Transkrip Audio

Audio ke teks pakai Whisper, jalan di browser kamu sendiri. Gratis, file tidak diupload ke mana pun.

Klik atau tarik file audio ke sini mp3, wav, m4a, ogg, atau video mp4

Pertama kali pakai sebuah model, browser mengunduhnya dulu (butuh internet), setelah itu tersimpan di cache. Paling lancar di Chrome atau Edge.
